# SOP_TAKEDOWN — 임시조치(takedown) 표준 운영 절차

본 문서는 Packlinx 플랫폼에 게시·노출된 정보 중 사생활 침해, 명예훼손, 부정경쟁, 표시·광고 위반, 사실 오기(誤記) 등 타인의 권리를 침해한다고 주장되는 정보에 대한 신고 접수, 검토, 임시조치, 본조치, 통지, 기록 보존의 전 절차를 규정한다.

## 1. 목적·적용 범위

### 1.1 목적
Packlinx 플랫폼(웹사이트, 모바일 앱, 검색결과 페이지, 벤더 카드, 이용자 후기 등)에 게시된 정보 중 다음 각 호에 해당하여 타인의 권리를 침해한다고 주장되는 게시물에 대해 정보통신망법 제44조의2 가 정한 임시조치(접근 차단·게시 중단) 의무를 적시에 이행하기 위한 절차를 규정한다.

1. **사생활 침해** — 개인정보·사생활의 무단 노출
2. **명예훼손** — 사실의 적시 또는 허위사실로 인한 명예 훼손
3. **부정경쟁행위** — 타인의 영업표지·상품 이미지·신용 등의 무단 도용
4. **표시·광고법 위반** — 거짓·과장·기만적 표시·광고, 부당한 비교·비방
5. **사실 오기** — 벤더 정보(상호, 사업자번호, 통신판매업 신고번호, 서비스 범위 등) 의 명백한 오류

### 1.2 적용 범위
- 자사 운영 정보(편집부 작성 콘텐츠, 벤더 카드 메타데이터)
- 이용자 게시 정보(후기, 댓글, Q&A, 신고 양식 첨부)
- 외부 데이터 수집(크롤링/API) 으로 노출된 제3자 정보
- 검색결과 페이지·추천 슬롯·랭킹 상 노출되는 모든 텍스트·이미지

### 1.3 법적 근거 요약
- **정보통신망법 제44조의2 제2항**: 사업자는 신고를 받은 즉시 필요한 조치를 취하고 이를 신청인 및 게시자에게 통지하여야 한다.
- **시행령 제13조**: 임시조치 기간은 게시중단일로부터 **30일 이내**로 한다.
- **정보통신망법 제44조의2 제4항**: 권리침해 여부 판단이 어렵거나 이해당사자 간 다툼이 예상되는 경우, 사업자는 30일 이내의 임시조치를 취할 수 있다(임의의 임시조치 — 동법 §44조의3 도 함께 적용).
- **정보통신망법 제74조 제1항 제3호**: 명예훼손 정보에 대한 임시조치 의무 미이행 시 벌칙(3천만원 이하 과태료 또는 형사책임 가능).

## 3. 신고 양식 — 필수 정보 항목

신고에는 **다음 정보가 모두 포함되어야 한다**. 누락 시 **§5-1 보완 요청 절차**를 따른다.

### 3.1 신고자 정보
- 성명 (법인의 경우 상호 + 대표자)
- 연락처 (이메일 — 필수, 전화번호 — 선택)
- 신고자가 권리자 본인인지 / 대리인인지 표시
  - 대리인인 경우: 위임장 또는 대리권 증빙 첨부
- 본인 확인 자료 (개인: 성명·생년월일·자필 서명 / 법인: 사업자등록증 사본)

### 3.2 침해 게시물 식별 정보
- 침해를 주장하는 게시물의 **정확한 URL** (필수)
- 게시물 제목·작성자(노출명) — 확인 가능한 범위에서
- 게시일자(추정 가능 시)
- 화면 캡처 (전체 화면 + 침해 부분 강조)

### 3.3 침해 유형 및 근거
- 침해 유형: §1.1 의 분류 중 택1 이상
- 침해의 구체적 사실관계 (5W1H 서술)
- 권리 근거:
  - 명예훼손/사생활: 침해되는 권리·사실의 진실성 부정 사유
  - 부정경쟁/상표: 등록증, 등록번호, 사용 증거
  - 저작권: 저작권 등록부 또는 창작 증거
  - 표시광고법: 사실관계 비교 자료
  - 사실 오기: 정정 자료(공식 등기부등본, 사업자등록증 등)

### 3.4 신청 취지
- 요청 사항: 게시중단 / 정정 / 삭제 / 임시조치 / 기타
- 임시조치 동의 여부: "권리침해 여부 판단이 곤란한 경우 30일 이내 임시조치에 동의함" 의 명시 체크

### 3.5 신고자 서명·일자
- 전자 서명 또는 자필 서명 캡처
- 신고일자

### 3.6 허위신고에 대한 안내

## 4. 검토·접수확인·임시조치 발동 SLA

| 단계 | 조치 | SLA (영업시간 기준) | 산정 근거 |
| --- | --- | --- | --- |
| 4.1 접수확인 | 신고자에게 접수번호 + 처리 SLA 자동 회신 | **4시간 이내** | 내부 운영 SLA |
| 4.2 1차 형식 검토 | 양식 누락·식별불가 여부 확인 | **24시간 이내** | 내부 운영 SLA |
| 4.3 보완 요청(필요 시) | §5-1 절차 발동 | 1차 검토 종료 즉시 | — |
| 4.4 2차 실질 검토 | 침해 주장의 표면적 타당성 (prima facie) 검토 | **48시간 이내** (양식 충족 시) | 내부 운영 SLA |
| 4.5 임시조치 발동 | 명백한 침해/판단 곤란 시 게시 중단(접근 차단) | **2차 검토 종료 즉시 — 늦어도 신고 후 영업일 기준 72시간 이내** | 정보통신망법 §44-2 "지체없이" 해석 + 동 시행령 §13 30일 |
| 4.6 통지 | 신고자·게시자 양쪽에 임시조치 결과 통지 | 발동과 동시에 (24시간 이내) | 정보통신망법 §44-2 제3항 |

> **참고**: 정보통신망법 제44조의2 제2항의 "지체없이" 는 사안의 명확성·증빙 충실도에 따라 달라진다. 명예훼손·사생활 침해 등 인격권 침해가 명백한 경우 24시간 이내 발동을 목표로 한다. 판단 곤란 시 §44조의3 임의의 임시조치를 발동하고 그 사실을 통지한다.

## 5. 보완 요청·거부 사유·재신고 안내

### 5.1 보완 요청 절차
1차 형식 검토(§4.2) 결과 다음 사유 중 하나가 확인되면 신고자에게 보완을 요청한다.
- 신고자 본인 확인 자료 누락
- 침해 게시물 URL 미특정 또는 캡처 불일치
- 침해 유형·근거 불명확
- 대리인 신고의 위임장 누락
- 서명·일자 누락

**보완 요청 통지**: 접수번호와 함께 누락 항목을 구체적으로 명시하여 이메일/웹폼 회신으로 발송. 보완 기한은 **7영업일**. 보완 시 SLA 는 보완 자료 수령 시점부터 재기산.

### 5.2 거부 사유
다음의 경우 임시조치를 거부하고 그 사유를 신고자에게 통지한다.
- 신고 내용이 권리 침해와 무관 (예: 단순 의견 불만, 가격 비교 요청)
- 동일 게시물에 대해 이미 임시조치·본조치가 종결되어 변경 사유가 없는 재신고
- 명백히 표현의 자유 범위 내에 있는 비평·평가 (사실 적시가 아닌 의견)
- 보완 요청 후 7영업일 내 보완 미이행
- 허위신고 정황이 명백한 경우

거부 통지는 거부 사유 + 이의신청 안내 + 외부 분쟁조정 채널(방송통신심의위원회, 개인정보분쟁조정위원회 등) 안내를 포함한다.

### 5.3 재신고 안내
거부된 신고도 새로운 사실관계·증빙이 있으면 재신고 가능. 단순 동일 자료 반복 제출은 새 신고로 접수하지 않는다.

## 6. 임시조치 실행 (게시중단)

### 6.1 게시중단 처리
- 해당 게시물·벤더 페이지(또는 침해 영역) 를 **비공개(접근 차단)** 처리.
- 차단된 자리에는 정보통신망법 제44조의2 에 따른 임시조치 표시:
  > "본 게시물은 권리침해 신고 접수에 따라 정보통신망법 제44조의2 에 따라 임시 게시 중단된 상태입니다. 임시조치 기간: YYYY-MM-DD ~ YYYY-MM-DD (30일 이내)."

### 6.2 게시자 통지 (정보통신망법 §44-2 제3항)
- 임시조치와 **동시에** 게시자에게 통지:
  - 임시조치 사실
  - 신고 요지 (신고자 개인정보 일부 마스킹 — PIPA §17 ·§18 균형)
  - 임시조치 기간 (게시중단일 ~ 30일 이내)
  - 이의제기 절차 (§7) 안내
- 통지 채널: 게시자 등록 이메일 — 주채널, 미설정 시 게시 시점 입력 연락처.

### 6.3 30일 만료 시 자동 처리
- 30일 만료 시점 24시간 전 운영팀(Legal Counsel + CEO) 에게 자동 알림.
- 만료일까지 게시자 이의 / 신고자 추가 자료 / 본조치 결정이 없으면 §8.3 "원상회복" 진행 (정보통신망법 §44-2 제5항: "신청인의 본안 신청이 없는 경우 임시조치는 종료").

## 7. 게시자 이의·본조치 결정

### 7.1 이의신청
- 게시자는 임시조치 통지 수령 후 **30일 이내** 이의신청 가능.
- 이의신청에는 다음 자료를 포함:
  - 게시자 본인 확인 자료
  - 침해 사실 부인 또는 정당한 사용 근거 (사실 진실성, 적법한 인용·비평, 정당한 비교광고 등)
  - 첨부 증거

### 7.2 이의 검토 및 결정
- Legal Counsel 자문 + CEO 결재로 **이의 접수 후 7영업일 이내** 결정.
- 결정 유형:
  - **본조치(영구 삭제 또는 게시 차단 유지)**: 침해가 명백·중대
  - **원상회복**: 침해가 입증되지 않거나 표현의 자유 우위
  - **분쟁조정 회부 권고**: 양측 주장이 첨예하게 대립하는 경우 — 방송통신심의위원회 명예훼손 분쟁조정부, 한국저작권위원회, 공정거래위원회(표시광고) 등.

### 7.3 결정 통지
신고자·게시자 양측에 결정 사실, 사유 요지, 이후 절차(소송·분쟁조정 등) 안내를 포함한 통지서 발송.

## 8. 본조치 / 원상회복

### 8.1 본조치 (영구 삭제)
- 침해가 인정되어 본조치가 결정된 경우 게시물 영구 삭제 + 사이트 검색·인덱스에서 제거.
- 캐시·외부 검색엔진(NAVER/Google) 캐시 삭제 요청 동시 진행.
- 동일·유사 게시물의 재게시 모니터링(7일).

### 8.2 부분 정정
- 사실 오기(§1.1 ⑤) 의 경우 게시물 전체 삭제 대신 해당 부분만 정정 + 정정 일자·정정 요지 표시.

### 8.3 원상회복
- 임시조치 사유 소멸 또는 게시자 이의 인용 시 원상회복.
- 원상회복 시 차단 표시 제거 + 기존 URL·시점 정보 유지.
- 임시조치 기록은 §9 에 따라 보존.
